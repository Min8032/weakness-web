## 打开播放器

**https://min8032.github.io/weakness-web/**

- 微信：复制链接 → 在浏览器中打开  
- iPhone：Safari 打开后可「添加到主屏幕」

功能与 Android 版相同：断点续播、章节列表、顺序/单曲/随机、定时停止、静音。
